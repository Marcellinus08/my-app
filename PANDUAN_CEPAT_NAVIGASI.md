# 📱 Panduan Cepat - Navigasi untuk Tuna Netra

**Quick Start Guide | Versi Singkat & Praktis**

---

## ⚡ 5 Langkah Memulai Navigasi

### 1️⃣ Buka Aplikasi
- Tap ikon aplikasi "My App" di home screen
- Tunggu 2-3 detik loading

### 2️⃣ Masuk ke Menu Navigasi
- Dari Home Screen, tap **"🗺️ NAVIGASI"**
- Izinkan GPS (tap "Izinkan") jika muncul dialog

### 3️⃣ Pilih Destinasi
Pilih salah satu cara:

**A. Dari Tempat Favorit**
- Swipe untuk memilih tempat
- Tap tempat yang ingin dituju

**B. Dari Pencarian**
- Tap **"Cari Tempat"**
- Ketik nama atau alamat
- Pilih dari hasil

### 4️⃣ Review & Mulai
Cek:
- ✓ Jarak & waktu perjalanan
- ✓ Nama destinasi benar

Tap **"Mulai Navigasi"**

### 5️⃣ Ikuti Instruksi
- Sistem akan membaca instruksi otomatis
- Ikuti petunjuk arah
- Saat tiba, akan ada notifikasi

## 📱 Setup Awal (First Time)

### Langkah 1: Download & Install
1. Buka Play Store
2. Cari "My App Navigation"
3. Tap "Install"
4. Tunggu download & install selesai

### Langkah 2: Buat Akun
1. Tap "Daftar" jika pertama kali
2. Masukkan:
   - Nama lengkap
   - Email
   - Password
3. Tap "Daftar"
4. Verifikasi email (cek inbox)

### Langkah 3: Setup Profil
1. Masukkan nama Anda
2. Upload foto profil (opsional)
3. Tambahkan kontak darurat
4. Pilih preferensi bahasa: **Bahasa Indonesia**

### Langkah 4: Setup Aksesibilitas
1. Menu → ⚙️ Pengaturan
2. Masuk "Aksesibilitas"
3. Aktifkan TalkBack (jika belum)
4. Atur kecepatan pembacaan (1.0x recommended)
5. Test audio

### Langkah 5: Setup GPS & Bluetooth
1. Aktifkan GPS di Pengaturan Sistem
2. Hubungkan Smartcane (Bluetooth)
3. Test GPS: Buka Maps 5 menit
4. Done! ✓

## 🔴 Troubleshooting Cepat

### ❌ GPS Tidak Jalan

**Penyebab**: GPS mati atau tidak akurat

**Solusi**:
1. Pengaturan → Lokasi → Aktifkan
2. Pilih "Precision Location"
3. Buka Google Maps 5 menit untuk warm-up
4. Coba navigasi lagi

---

### ❌ Smartcane Tidak Terhubung

**Penyebab**: Bluetooth off atau tidak dipasang

**Solusi**:
1. Nyalakan Bluetooth di ponsel
2. Nyalakan Smartcane (tekan 3 detik)
3. Buka Menu → Koneksi Bluetooth
4. Tap "Scan" & tunggu ditemukan
5. Tap smartcane & ikuti pairing

---

### ❌ Suara Tidak Keluar

**Penyebab**: Volume media/ponsel terlalu rendah

**Solusi**:
1. Tekan tombol Volume Atas beberapa kali
2. Periksa pengaturan TTS:
   - Menu → ⚙️ Pengaturan → Aksesibilitas
   - Volume: set ke 80-100%
3. Restart aplikasi

---

### ❌ Rute Tidak Ditemukan

**Penyebab**: Tidak ada internet atau destinasi invalid

**Solusi**:
1. Periksa koneksi WiFi/Mobile data
2. Coba cari tempat lain
3. Restart aplikasi
4. Clear cache: Pengaturan → Apps → Clear Cache

---

### ❌ Sering Off-Route

**Penyebab**: GPS tidak akurat atau jalan memutar

**Solusi**:
1. Jalan lurus mengikuti instruksi
2. Hindari area dengan bangunan tinggi
3. Update GPS: Buka Maps sejenak
4. Coba rute yang lebih lurus

## ☎️ Tombol SOS (Darurat)

### Cara Menggunakan

1. **Situasi Darurat?** Tahan tombol Home 5 detik
2. Atau: Menu → Kontak Darurat → **Tombol SOS**
3. Sistem akan:
   - ✓ Kirim SMS lokasi ke keluarga
   - ✓ Call nomor SOS pertama
   - ✓ Share live location

### Setup SOS

1. Menu → ⚙️ Pengaturan
2. Pilih "Kontak Darurat"
3. Tambah minimal 2 kontak
4. Set kontak pertama sebagai "SOS Primary"

1. Saat navigasi aktif, tap **"⭐ Simpan Tempat"**
2. Berikan nama (mis: "Rumah", "Kantor")

## 🔊 Pengaturan Suara (TTS)

### Menu Aksesibilitas

**Path**: Menu → ⚙️ Pengaturan → Aksesibilitas

| Setting | Rekomendasi |
|---------|-------------|
| **Bahasa** | Bahasa Indonesia (id-ID) |
| **Kecepatan** | 0.9 - 1.1 (normal) |
| **Pitch** | 1.0 (normal) |
| **Volume** | 80-100% |

### Test Audio
1. Tap "Test Audio"
2. Dengarkan sampel pembacaan
3. Jika tidak jelas, sesuaikan kecepatan/pitch

## 🎓 Tips & Trik

### 💡 Tip 1: Cek Rute Sebelum Berangkat
- Tap "Detail Rute" untuk melihat turn-by-turn
- Bisa membantu persiapan mental

### 💡 Tip 2: Gunakan Pause Saat Berhenti
- Saat istirahat, pause navigasi (3-finger tap)
- Jangan stop, supaya durasi tetap update

### 💡 Tip 3: Set Kontak Darurat
- Minimal 2 kontak (keluarga & dokter/karib)
- Update rutin jika berubah

### 💡 Tip 4: Aktifkan Live Location
- Bagikan lokasi dengan keluarga saat navigasi
- Mereka bisa monitor perjalanan Anda

### 💡 Tip 5: Gunakan Tempat Favorit
- Semakin banyak favorit, semakin cepat navigasi
- Kategori memudahkan pencarian

## 🚨 Kode Error Umum

| Error | Penyebab | Solusi |
|-------|---------|--------|
| **GPS 001** | Sinyal GPS hilang | Keluar ruangan, tunggu 30 detik |
| **NET 001** | Tidak ada internet | Check WiFi/Mobile data |
| **BT 001** | Smartcane terputus | Pair ulang Bluetooth |
| **NAV 001** | Rute tidak ditemukan | Ubah destinasi, cek koneksi |
| **TTS 001** | Suara tidak jalan | Cek volume, restart app |
