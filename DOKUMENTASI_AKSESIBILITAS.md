## 🔧 Aktivasi & Setup

### Langkah 1: Aktivasi TalkBack (Android)

1. **Buka Pengaturan Sistem**
   - Tap Settings di home screen
   - Cari "Accessibility" atau "Aksesibilitas"

2. **Pilih TalkBack**
   - Masuk Accessibility menu
   - Tap "TalkBack" atau "Screen Reader"

3. **Aktifkan TalkBack**
   - Toggle ON untuk mengaktifkan
   - Konfirmasi dialog "Turn on TalkBack?"
   - Tap "OK"

4. **Ikuti Tutorial**
   - Sistem akan membaca dialog tutorial
   - Ikuti instruksi pada screen
   - Pelajari gesture dasar

### Langkah 2: Setup Aplikasi

1. **Buka Aplikasi**
   - Find app icon
   - Double tap untuk open

2. **First Launch Setup**
   - Pilih bahasa: "Bahasa Indonesia"
   - Konsentrasikan perhatian pada instruksi audio
   - Follow on-screen prompts

3. **Accessibility Settings**
   - Menu → Settings → Accessibility
   - Aktifkan semua fitur yang diinginkan
   - Test setiap fitur

### Langkah 3: Konfigurasi Utama

#### TTS Configuration
```
Menu → Settings → Accessibility → Text-to-Speech

1. Language: "Bahasa Indonesia (id-ID)"
2. Speed: 1.0 (normal) - sesuaikan dengan kenyamanan
3. Pitch: 1.0 (normal)
4. Volume: 80% (rekomendasi)
5. Tap "Test" untuk verifikasi
```

#### High Contrast
```
Menu → Settings → Display → High Contrast

1. Enable: ON
2. Theme: Dark (recommended)
3. Contrast Level: Maximum
```

#### Font Size
```
Menu → Settings → Display → Font Size

Options:
- Small (14sp)
- Normal (16sp) - default
- Large (18sp)
- Extra Large (20sp)
- Huge (24sp)
```

## 🔊 Screen Reader (TalkBack)

### Apa itu TalkBack?

TalkBack adalah screen reader bawaan Android yang membaca semua elemen UI secara verbal. Dengan TalkBack, Anda dapat:
- ✓ Mendengarkan label & konten setiap button/field
- ✓ Navigasi UI menggunakan gesture
- ✓ Operate aplikasi tanpa melihat layar

### Mengaktifkan TalkBack Pertama Kali

```
Pengaturan → Accessibility → TalkBack → ON

Catatan: Pertama kali aktivasi akan ada dialog konfirmasi.
Tap di area mana pun screen untuk lanjut.
```

### Gesture TalkBack Dasar

#### Navigation Gestures

| Gesture | Fungsi | Deskripsi |
|---------|--------|-----------|
| **Single Tap** | Select/Focus | Memilih elemen, membaca labelnya |
| **Double Tap** | Activate | Mengaktifkan button/link |
| **Swipe Kanan** | Next Item | Pindah ke elemen berikutnya |
| **Swipe Kiri** | Previous Item | Pindah ke elemen sebelumnya |
| **Swipe Bawah** | Next Page | Scroll ke bawah |
| **Swipe Atas** | Previous Page | Scroll ke atas |

#### Advanced Gestures

| Gesture | Fungsi | Deskripsi |
|---------|--------|-----------|
| **2-Finger Swipe Kanan** | Skip Next Item | Lewati elemen & lanjut |
| **2-Finger Swipe Kiri** | Skip Previous | Kembali ke elemen sebelumnya |
| **2-Finger Swipe Bawah** | Page Down | Scroll cepat ke bawah |
| **2-Finger Swipe Atas** | Page Up | Scroll cepat ke atas |
| **2-Finger Double Tap** | Read All | Membaca semua elemen |
| **3-Finger Tap** | Pause/Resume | Pause pembacaan |

### TalkBack Settings untuk Optimal Use

```
Pengaturan → Accessibility → TalkBack → Settings

Recommended Configuration:

1. Reading Controls
   - Verbosity: Medium (not too verbose)
   - Spell out names: OFF
   - Use pitch changes: ON

2. Sound & Vibration
   - Use sound: ON
   - Use vibration: ON
   - Volume: Default

3. Advanced
   - Continuous reading: OFF (manual)
   - Single-tap mode: OFF (use swipes)
```

### Tips Menggunakan TalkBack

#### 💡 Tip 1: Pahami Reading Order
- TalkBack membaca dari atas ke bawah
- Elemen penting (buttons) dibaca terlebih dahulu
- Swipe kanan/kiri untuk navigasi terstruktur

#### 💡 Tip 2: Gunakan Reading Menu
- 2-Finger Swipe Bawah → Reading Menu
- Akses ke heading, links, form fields
- Navigasi cepat ke elemen tertentu

#### 💡 Tip 3: Local Context Menu
- 2-Finger Swipe Kanan → Local Context Menu
- Akses quick actions untuk elemen saat ini
- Context-sensitive help tersedia

#### 💡 Tip 4: Touch Exploration
- Dapat matikan dengan Single Tap
- Aktifkan kembali dengan gesture tertentu
- Gunakan untuk eksplorasi area

## 🎤 Text-to-Speech (TTS)

### Apa itu Text-to-Speech?

TTS adalah engine yang mengkonversi teks menjadi suara. Aplikasi menggunakan:
- **Engine**: Google TTS (built-in)
- **Bahasa**: Bahasa Indonesia (id-ID)
- **Kualitas**: Natural sounding speech
- **Kustomisasi**: Speed, pitch, volume

### Konfigurasi TTS Optimal

#### Basic Setup

```
Menu → Settings → Accessibility → Text-to-Speech

1. Engine Selection
   - Default: Google Text-to-Speech
   - Install jika belum ada

2. Language
   - Select: Bahasa Indonesia (Indonesia)
   - NOT English!

3. Speed Configuration
   - Slower (0.5x - 0.8x): Lebih jelas
   - Normal (1.0x): Standard
   - Faster (1.2x - 1.5x): Lebih cepat
   - Very Fast (1.8x - 2.0x): Sangat cepat

4. Pitch Configuration
   - Lower (0.8): Pitch rendah
   - Normal (1.0): Standard
   - Higher (1.2): Pitch tinggi

5. Volume Configuration
   - Soft: 50-60%
   - Normal: 70-80% (recommended)
   - Loud: 90-100%
```

#### Advanced Configuration

```
Engine Settings:

1. Neural Network
   - If available: ON (lebih natural)
   - Fallback: Standard (jika device lama)

2. Prosody Control
   - Intonation: ON
   - Emphasis: ON

3. Audio Optimization
   - Equalization: ON
   - Bass Boost: OFF
   - Treble: NORMAL
```

### Test Audio

Sebelum navigasi aktif, test TTS:

1. **Menu → Settings → Accessibility → TTS**
2. **Tap "Test Audio"**
3. **Dengarkan: "Selamat datang di aplikasi navigasi"**

Jika tidak jelas:
- Naikkan volume
- Turunkan/naikkan speed
- Ubah pitch

### Instruksi yang Dibaca Otomatis

Selama navigasi aktif, TTS akan membaca:

| Konten | Contoh |
|--------|--------|
| **Instruksi Arah** | "Lurus 50 meter, kemudian belok kanan" |
| **Landmark** | "Di depan bank" |
| **Distance Update** | "Sisa 200 meter" |
| **Time Update** | "Estimasi 2 menit 30 detik" |
| **Off-Route Alert** | "Anda keluar dari rute" |
| **Arrival Alert** | "Anda telah sampai di destinasi" |
| **Error Messages** | "GPS sinyal hilang" |

### Speech Rate Recommendations

| Pengguna | Rekomendasi | Catatan |
|----------|-------------|--------|
| **Pemula** | 0.8x - 0.9x | Lebih mudah dipahami |
| **Berpengalaman** | 1.0x - 1.1x | Balance antara cepat & jelas |
| **Advanced** | 1.3x - 1.5x | Untuk pengguna terbiasa |
| **Sangat Cepat** | 1.8x - 2.0x | Untuk expert users |

## 🎨 High Contrast & Font Sizing

### Mengaktifkan High Contrast Mode

```
Menu → Settings → Display → High Contrast → ON

Automatic Setup:
- Background: Pure Black (#000000)
- Text: Pure White (#FFFFFF)
- Buttons: High contrast colors
- Borders: Bold, visible
```

### Font Size Options

Aplikasi mendukung 5 tingkat ukuran:

```
Menu → Settings → Display → Font Size

Pilihan:
1. Small (14 sp) - untuk screen besar
2. Normal (16 sp) - default, standard
3. Large (18 sp) - rekomendasi untuk gangguan penglihatan
4. Extra Large (20 sp) - untuk low vision
5. Huge (24 sp) - untuk very low vision

Preview: Aplikasi akan show preview sebelum apply.
```

### Contrast Enhancement

```
Settings → Display → Contrast Level

Options:
- Normal (default)
- High (medium enhancement)
- Maximum (maximum enhancement)
- Ultra (experimental, very strong)

Recommended: High untuk sebagian besar pengguna
            Maximum untuk severe low vision
```

### Text Styling

```
Settings → Display → Text Style

Available Options:
- Font Family: Sans Serif (recommended)
- Font Weight: Bold (rekomendasi untuk clarity)
- Letter Spacing: Normal / Wide / Extra Wide
- Line Spacing: Normal / Loose / Extra Loose
```

### Color Inversion

```
Settings → Display → Color Inversion → ON

Fungsi: Membalikkan semua warna untuk kontras lebih
- Putih → Hitam
- Hitam → Putih
- Biru → Kuning

Note: Tidak recommended untuk navigasi (map jadi membingungkan)
```

## 💡 Tips & Trik Aksesibilitas

### Untuk Screen Reader Users

#### 💡 Tip 1: Gunakan Reading Menu
- Swipe dengan 2 jari ke bawah untuk akses reading menu
- Navigasi cepat ke headings & links
- Lebih efisien daripada swipe one-by-one

#### 💡 Tip 2: Learn TalkBack Shortcuts
- Customize gesture shortcuts di TalkBack settings
- Common shortcuts akan mempercepat navigasi
- Practice di aplikasi lain dulu sebelum navigasi

#### 💡 Tip 3: Use Touch Exploration Mode
- Single tap untuk activate/explore area
- Useful untuk pemula yang belum hafal gestures
- Dapat di-toggle dengan Settings

#### 💡 Tip 4: Enable Sound Feedback
- Turn on haptic + sound untuk double confirmation
- Helpful ketika GPS unstable
- Vibration + sound = confident navigation

### Untuk TTS Users

#### 💡 Tip 1: Calibrate Speed
- Jangan terlalu cepat (>1.5x) untuk perjalanan pertama
- Mulai dengan 0.9x - 1.0x
- Naikkan speed seiring pengalaman

#### 💡 Tip 2: Use Pitch Adjustment
- Pitch lebih tinggi (1.1-1.2): Lebih mudah didengar di area bising
- Pitch normal (1.0): Untuk environment tenang
- Test di berbagai setting sebelum navigasi aktual

#### 💡 Tip 3: Volume Management
- Set volume di aplikasi, bukan sistem volume
- Aplikasi volume override system (untuk safety)
- Gunakan headphones untuk privacy

### Untuk Low Vision Users

#### 💡 Tip 1: Kombinasi Font + Contrast
- Large Font (20sp) + Maximum Contrast = Optimal
- Test combination di berbagai lighting conditions
- Adjust berdasarkan preferensi pribadi

#### 💡 Tip 2: Use Dark Mode
- Dark mode lebih mudah dibaca di outdoor
- Kurangi glare dari matahari
- Battery juga lebih tahan di OLED screens

#### 💡 Tip 3: Enable Screen Magnification
- Android built-in magnification bisa membantu
- Zoom up to 5x untuk bagian tertentu
- Combine dengan high contrast untuk best result

## 🆘 Troubleshooting Aksesibilitas

### ❌ TalkBack Tidak Bekerja

**Gejala**: Screen reader tidak membaca apa-apa

**Penyebab Umum**:
- TalkBack belum diaktifkan
- Device permissions tidak diberikan
- Bug atau crash

**Solusi**:
1. Buka Pengaturan → Accessibility → TalkBack
2. Toggle OFF kemudian ON kembali
3. Berikan permission jika diminta
4. Restart device
5. Reinstall aplikasi jika masih tidak jalan

---

### ❌ TTS Tidak Berbunyi

**Gejala**: Tidak ada suara pembacaan

**Penyebab Umum**:
- Volume media terlalu rendah
- TTS engine tidak installed
- Bahasa salah

**Solusi**:
1. Tekan tombol Volume Up 5x
2. Check Pengaturan → TTS Engine → Google TTS installed?
3. Pilih bahasa: "Bahasa Indonesia" bukan "English"
4. Test audio di settings
5. Restart aplikasi

---

### ❌ Gesture Tidak Bekerja

**Gejala**: Swipe/tap tidak merespon

**Penyebab Umum**:
- Gesture tidak tepat
- Screen lock atau app minimize
- Device setting override

**Solusi**:
1. Ensure TalkBack ON
2. Practice gesture dengan slow & deliberate motion
3. Baca TalkBack tutorial ulang
4. Check device tidak dalam "sleep mode"
5. Disable "one-handed mode" jika enabled

---

### ❌ Font Size Tidak Berubah

**Gejala**: Font masih kecil meski sudah set besar

**Penyebab Umum**:
- Setting belum apply
- App cache belum clear
- System-level override

**Solusi**:
1. Menu → Settings → Display → Font Size → Select size
2. Tap "Apply"
3. Wait 2-3 second
4. If not working: Restart app
5. If still not: Clear cache → Pengaturan → Apps → Clear Cache

---

### ❌ High Contrast Mode Buram

**Gejala**: Layar hitam putih tapi tidak jelas

**Penyebab Umum**:
- Contrast level terlalu tinggi
- Maps image quality down
- Display setting conflict

**Solusi**:
1. Try lower contrast level (High instead of Maximum)
2. Ensure Dark Mode enabled (not inversi)
3. Adjust brightness in Pengaturan → Display
4. Test di berbagai lighting condition
